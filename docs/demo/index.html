QuickFix — Features Demo

Machine-learning translation & summarization, live on this page.

What you can try

  • Pick any app language at sign-up (list comes from the API, not code)
  • Worker profiles show full completed-work history with rank progress (156 jobs / year per step)
  • Rank emblems: Apprentice → Grandmaster
  • "Write a review" → stars + text in your language, updates the rating
  • "Translate" on any foreign review → ML translation into your app language, with method + confidence
  • "Overall summary" → TF-IDF extractive summary, 1–2 paragraphs depending on review count
  • Book, chat (auto-reply), complete a job, add a language (admin)

ML under the hood

  • Translation: statistical MT trained in-browser-server startup from a 43-sentence en/ur/fr/hi parallel corpus — word Bayes model + phrase table + translation memory, English pivot.
  • Summarization: TF-IDF extractive scoring with sentiment lexicons.
  • Production app uses the neural Cloud Translation proxy (backend/translation-proxy) + LLM summary endpoint.
